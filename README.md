# 🎙 IELTS Speaking Studio

실전처럼 듣고 말하고, 원어민 표현으로 교정받고, 그 표현을 외우는 IELTS 스피킹 연습 사이트입니다.
서버 없이 브라우저만으로 동작해서 **GitHub Pages에 무료로 올릴 수 있어요.**

## 기능
- **실전 모의고사**: Part 1 → 2 → 3 전체 진행. 시험관이 호주 억양으로 질문을 읽어 주고, 질문이 끝나면 녹음이 자동으로 시작돼요. Part 2는 1분 준비 후 2분이 되면 자동으로 끊겨요.
- **파트별 연습**: 한 문제씩 답하고 바로 교정을 받아요. 교정본을 본 뒤 같은 질문에 다시 답할 수 있어요.
- **4-3-2 연습**: 같은 큐카드로 4분, 3분, 2분 세 번 말하고, 라운드별 속도와 군말 변화를 비교해요.
- **AI 교정** (Gemini): 녹음을 직접 듣고 군말까지 그대로 받아쓴 뒤 다음을 만들어요.
  - 내 생각은 그대로 살린 원어민식 교정본 (구어체, 고급 어휘, 정확한 문법)
  - 주요 수정 포인트와 이유
  - 암기용 표현 정리 (뜻, 강세, IPA, 원래 내가 한 말, 새 예문)
  - 채점 기준별 예상 밴드와 한국어 피드백
- **음성**: 교정본 전체 듣기, 천천히 듣기, 문장을 클릭해서 한 문장씩 듣기(쉐도잉용)
- **표현 뱅크와 복습**: 한국어 뜻을 보고 영어로 말하는 방향으로 복습해요. 간격 반복(1·2·4·8·16·32일)을 쓰고, Anki로 내보낼 수도 있어요.
- **기록**: 연속 연습일, WPM(분당 단어 수) 추이, 지난 답변과 녹음 다시 보기

## GitHub Pages에 올리기 (5분)
1. GitHub에서 **New repository**를 만들어요. 이름은 예를 들어 `ielts-speaking`, **Public**으로 설정합니다.
2. 저장소 페이지에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더(`index.html`, `css/`, `js/`, `README.md`)를 끌어다 놓은 뒤 **Commit**을 눌러요.
3. **Settings → Pages**로 가서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 선택하고 **Save**를 눌러요.
4. 1~2분 뒤 `https://<내아이디>.github.io/ielts-speaking/` 주소로 접속하면 돼요.
5. 사이트의 **설정**에서 Gemini API 키를 넣어요. 키는 https://aistudio.google.com/apikey 에서 무료로 발급받을 수 있어요.

> 저장소는 공개지만, API 키와 내 답변, 녹음은 **내 브라우저 안에만** 저장되고 GitHub에는 올라가지 않아요.

## 내 컴퓨터에서 바로 실행하기
`index.html`을 더블클릭하면 동작하지 않아요(브라우저 보안 정책 때문). 대신 터미널에서 다음을 실행하세요.
```
cd ielts-speaking
python3 -m http.server 8000
```
그다음 http://localhost:8000 으로 접속하면 돼요.

## 비용과 주의점
- GitHub Pages, 브라우저 녹음, 브라우저 음성은 모두 무료예요.
- Gemini API는 결제 정보를 등록하지 않으면 무료 등급으로만 동작해요. 무료 등급에는 분당/일일 요청 한도가 있어서, 모의고사(답변 약 14개)는 교정이 순서대로 천천히 진행될 수 있어요. 무료 등급의 조건과 모델 이름은 Google이 바꿀 수 있어요. 모델 이름이 바뀌면 설정 → 고급에서 고치면 돼요.
- 무료 등급에서는 입력 내용이 Google 서비스 개선에 쓰일 수 있어요.
- 추천 브라우저: **Chrome** 또는 **Safari** (Mac). Firefox는 실시간 받아쓰기가 안 되지만, AI 받아쓰기는 돼요.
- 발음 점수는 AI의 대략적인 추정이에요. 강세는 표현 카드의 대문자 표기와 YouGlish로 확인하는 걸 추천해요.
- 문제는 연습용으로 새로 쓴 것이고, 공식 IELTS 문제가 아니에요.
